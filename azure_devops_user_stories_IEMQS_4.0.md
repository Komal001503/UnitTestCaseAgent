### Description

**As a** system administrator  
**I want to** create a new page with fields to store API configuration details  
**So that** I can manage and update API settings easily for integration purposes

### Acceptance Criteria

### **Fields with Data Types**
  1. **API URL** – _String_ (Mandatory) 
  2. **Method** – _String_ (Allowed values: GET, POST, PUT, DELETE) 
  3. **AuthType** – _String_ (Allowed values: API Key, Bearer Token, Basic Auth) 
  4. **Key** – _String_ (Visible if AuthType = API Key) 
  5. **Value** – _String_ (Visible if AuthType = API Key) 
  6. **Token** – _String_ (Visible if AuthType = Bearer Token) 
  7. **Username** – _String_ (Visible if AuthType = Basic Auth) 
  8. **Password** – _String (Encrypted)_ (Visible if AuthType = Basic Auth) 
  9. **RequestType** – _String_ (Allowed values: JSON, XML, Form-Data) 
  10. **IsActive** – _Boolean_ (Checkbox) 
  11. **ModifiedBy** – _String_ (Auto-populated with current user) 
  12. **ModifiedOn** – _DateTime_ (Auto-populated with current timestamp) 


* * *
### **Validation Rules**
  * **API URL** : Mandatory, must be a valid URL format 
  * **Method** : Mandatory, must be one of the allowed values 
  * **AuthType** : Mandatory, controls visibility of related fields 
  * **Password** : Must be stored securely (hashed/encrypted) 
  * **ModifiedOn** : System-generated, cannot be edited
